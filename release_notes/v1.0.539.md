# Dune Legacy Tornie 1.0.539 — Linux

Le troisième joueur rejoint désormais la partie même si les invités ne peuvent pas communiquer directement : après cinq secondes d'essai, l'hôte relaie les échanges, sans VPN. Le chemin direct reste utilisé lorsqu'il fonctionne.

**Tous les joueurs doivent installer 1.0.539, protocole 10, avec le même mod.** Sauvegardes : format 9831 conservé. L'hôte doit rester joignable et connecté.

Tests moteur et régression UDP réelle : lobby à trois joueurs, invités filtrés, messages et commandes de synchronisation, sélections, départ/reconnexion, époques et autorité de l'hôte. La CI Linux les exécute avant l'empaquetage. Une partie humaine sur trois connexions Internet distinctes reste à vérifier.

Formats Linux : AppImage, DEB, RPM et TAR.GZ. La version Windows précédente (1.0.538) reste disponible dans sa propre release et ne peut pas jouer avec 1.0.539.
