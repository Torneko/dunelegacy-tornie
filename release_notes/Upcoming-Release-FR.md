# Historique — demandes livrées en 1.0.547

Notes du 31 octobre 2026, après la version publiée **1.0.546**. Contenu livré en 1.0.547. Les contrôles locaux et les paquets Windows/Linux FR/EN sont consignés dans Validation-1.0.547.json.

## Interface en partie

- [x] Ajouter un bouton de **sélection d’armée**, placé **sous le bouton Chemical Carryall**.
- [x] Ajouter un bouton pour **sélectionner toutes les moissonneuses (Harvesters) du joueur**.

## Windtraps dans l’éditeur

- [x] Étendre aux Windtraps l’option **« Améliorée au départ »**, sur le modèle de celle des Rebels.
- [x] Rendre cette option disponible **même sans le mode Chaos**. Précision du 31 octobre : l’activation de Chaos n’est pas une condition dans l’éditeur.
- [x] Afficher une **étoile verte** sur les Windtraps dont cette option est activée dans l’éditeur.

## Super Tank — nouvelle unité

- [x] Remplacer l’Elite Siege Tank chez **Kleshmersh**, au prix de **925 crédits**.

- [x] Créer le **Super Tank** comme une **nouvelle unité**, avec sa propre identité plutôt qu’une simple modification de l’Elite Siege Tank.
- [x] En faire un **char de siège incendiaire**, avec **autant de points de vie que le Siege Tank standard**.
- [x] Lui donner des **tirs de feu à la manière du Rocket Launcher**.
- [x] Lui donner une **explosion sur le modèle du Devastator**.
- [x] Utiliser la tourelle dessinée par Tornie : [SuperTankGun.png](artwork/SuperTankGun.png). Une copie exacte du fichier `Images/Dune 2/Pixelart/SuperTankGun.png` est conservée dans le projet ; les différentes orientations sont présentes.
- [x] Intégrer l’**icône dédiée reçue** : [SuperTankIcon.png](artwork/SuperTankIcon.png), copie exacte de `Images/Dune 2/supertank.png` fournie par Tornie (91 × 55 pixels).
