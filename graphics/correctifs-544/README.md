# Aperçus des correctifs 1.0.544

Rendus du moteur corrigé, code `a30b766e80a58ec2b353262c9891fe4d24a056fc`. `Moissonneuses.png` compare la base vanilla aux deux livrées en couleurs Atreides et Ordos, dans les huit directions. `RangedTank.png` superpose les couches natives au même centre que `Tank::blitToScreen()`. Les pixels sont agrandis par voisin le plus proche, sans lissage. Les fichiers d’origine fournis par Tornie restent intacts.

Voir `release_notes/Validation-Correctifs-1.0.544.json` pour les contrôles réalisés. Ces aperçus ne remplacent pas les paquets publiés de la 1.0.544 initiale.
